# ЕГЭ на 100 — офлайн-версия

Приложение для подготовки к итоговому сочинению и ЕГЭ: русский, обществознание, английский.
Сделано из артефакта «ЕГЭ на 70» в Claude (с 31 октября 2026 — «ЕГЭ на 100»), но работает само по себе —
**без интернета и без подписки Claude**. Ставится на телефон значком, как обычное приложение.

**Адрес:** https://ddds555.github.io/dds55555/

## Что внутри

- **План на сегодня** — главный экран. Каждый день 2–4 шага на 30–45 минут, по этапам до экзамена:
  до 2 декабря — итоговое сочинение и русский, декабрь–январь — русский, обществознание и английский,
  февраль–март — сочинение ЕГЭ и пробники, апрель–май — пробники и повторение. Шаг отмечается сам, когда сделан
  (письменное на бумаге — кружком слева). После каждой тренировки — кнопка следующего шага. Весь план, этапы
  и вехи — «Весь план до ЕГЭ». Остальное (быстрые тренировки, обещания, вехи) — в «Ещё» внизу главной.
- **Авторы полностью** — тест на имя, отчество и фамилию с ловушками («Иван Александрович» вместо
  «Александр Иванович» Куприна) и с запоминалками; «Авторы моих книг» и «Мои книги вперемешку» — только по прочитанному.
- Всё, что было в версии в Claude: задания 1–27 по русскому, пробники, исключения, обществознание, английский,
  красная тетрадь, «Подтянуть», избранное, копилка и подарки.
- **Вкладка «Сочинение»** внизу экрана — итоговое сочинение: как писать, 33 произведения (с «Чудесным доктором»,
  «Кустом сирени» и «Кнопкой, кнопкой» Р. Мэтисона), темы ФИПИ, слова, тренировка, черновик.
- **Карточка произведения:** «Кратко» — сюжет в одном абзаце, под ним «Подробно» — пересказ по главам и эпизодам,
  чтобы не перепутать, кто что сделал. У небольших произведений — «Текст целиком».
- **«Слова»** — когда сочинение получается «водой» и с повторами: 25 слов к темам (доброта, милосердие,
  сострадание, равнодушие, совесть…) — что значит, близкие и противоположные слова, готовые сочетания, мысль
  для вступления; готовые фразы для каждой части сочинения; «было — стало» без воды; тренажёр синонимов.
- **Абзац-аргумент по своим книгам.** Кнопка «Аргумент к теме» на главной: тема подбирается к прочитанным
  произведениям, после — сверка с образцом (вход, эпизод, вывод, связь с темой).
- **«Прочитала → закрепила».** В карточке каждого произведения есть кнопка «Прочитала» и тест только по этой книге:
  автор, жанр, кто есть кто, аргументы (вспомнить эпизод и вывод, потом проверить себя) и вопросы как на сочинении.
  Во вкладке «Тренировка» видно, по каким книгам тест уже сдан.
- **Копия прогресса.** «Мои данные» (ссылка вверху главной): сохранить прогресс в файл и загрузить его обратно —
  так же переносится прогресс из версии в Claude.
- Без Claude не работают только проверки Claude (сочинение, абзац-аргумент, вопросы к заданию) — вместо них
  самопроверка по галочкам и карточкам. Когда есть интернет, кнопка «Скопировать для проверки Claude» копирует
  сочинение или абзац с просьбой проверить — остаётся вставить в чат с Claude.

## 1. Поставить на телефон

- **iPhone:** открыть адрес в Safari → «Поделиться» → «На экран «Домой»».
- **Android:** открыть адрес в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Открой приложение значком один раз с интернетом и подожди несколько секунд — появится «Приложение сохранено —
теперь работает без интернета». Дальше интернет не нужен (в самолёте тоже). Проверить можно в «Моих данных»:
там будет «без интернета — да».

## 2. Перенести прогресс из Claude

1. Сохрани на телефон файл копии прогресса (`ege70-progress-….json` или `ege100-progress-….json`).
2. В приложении: «Мои данные» → «Загрузить прогресс» → «Выбрать файл».

Прогресс хранится только на устройстве. Раз в неделю нажимай «Мои данные» → «Сохранить файл копии»:
если телефон потеряется или браузер очистит данные, копия всё вернёт.

## Новый значок «ЕГЭ на 100» на iPhone

Название и обложка внутри приложения обновляются сами. Значок на экране «Домой» iPhone не меняет: он запоминается,
когда приложение добавляют. Чтобы поставить новый значок и не потерять прогресс:

1. В старом приложении: «Мои данные» → «Сохранить файл копии» (сохрани в «Файлы»).
2. Удали старый значок с экрана «Домой».
3. Открой адрес в Safari → «Поделиться» → «На экран «Домой»».
4. В новом приложении: «Мои данные» → «Загрузить прогресс» → выбери сохранённый файл.

## Жалобы «Здесь ошибка?»

После ответа в задании можно нажать «Здесь ошибка?». Все такие жалобы собраны во вкладке «Ошибки» → «Жалобы»,
у каждой видно, проверена она или ждёт проверки. Без интернета их никто не проверяет: когда есть связь,
нажми «Скопировать для Claude» и вставь текст в чат с Claude.

Для Claude: проверить каждое задание по правилам ФИПИ (id в квадратных скобках - id задания в
`source/ege70-artifact.html`), ошибочные исправить через `CONTENT_FIXES` в `tools/build.py`, ответ по каждой жалобе
записать в `tools/report-checks.json` (`d` - дата проверки, `ok` - в задании всё верно или нет, `why` - объяснение
для ученицы), пересобрать и влить в `main`. После обновления приложения ответ появится у жалобы.

## Для компьютера

`docs/ege70-offline.html` — всё приложение одним файлом: скачать и открыть двойным щелчком в любом браузере,
интернет не нужен. Скачать можно и из самого приложения на компьютере («Мои данные»).

## Как обновить материалы

Материалы взяты из артефакта Claude (ссылка и версия — в `source/source.json`).
Если артефакт обновился:

1. Сохранить его HTML в `source/ege70-artifact.html`, поправить `version` и `updated` в `source/source.json`.
2. Запустить `python3 tools/build.py` — он соберёт `docs/`.
3. Закоммитить и влить в `main`. Сайт обновится сам, а установленное приложение покажет «Вышло обновление».

Сайт публикует GitHub Pages из ветки `gh-pages`. Её заполняет `.github/workflows/pages.yml`: при каждом изменении
`docs/` в `main` он кладёт содержимое `docs/` в корень `gh-pages`. Ветку `gh-pages` руками не правим.

Как устроено: `tools/build.py` берёт артефакт как есть, подключает шрифты из `docs/fonts` вместо Google Fonts,
меняет несколько мест (список `PATCHES`) и добавляет материалы из `tools/content` (подробные пересказы,
новые произведения, слова и фразы, авторы), `tools/offline.js`, `tools/plan.js` (план дня и главный экран)
и `tools/offline.css`.
Значки рисует `node tools/make-icons.cjs` (нужен Playwright). Шрифты Manrope и Unbounded — под лицензией SIL OFL
(`docs/fonts/OFL-*.txt`).
